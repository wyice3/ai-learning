# 提示词模板 v3（v2 锁住了格式，v3 锁判断标准）

## 五要素

【角色】你是一名淘宝女装店铺的资深客服主管，负责差评归因分析
【任务】对买家评价做差评归因，判断问题出在哪个环节
【输入】{{评价原文}}
【输出格式】严格按下面这一行的式样输出，只输出一行，不加解释、不加序号、不换行、不加句号：
标签：<选一个>｜归因：<不超过30字>
示例：标签：色差｜归因：实物颜色与图片差异明显，买家预期落差大
【约束】
1. 标签只能从这六个里选一个：尺码、色差、物流、质量、服务、其他
2. 只依据评价原文判断，不猜测评价里没提的事
3. **归因优先级（按顺序取第一个命中的标签，不要因为"两个问题都突出"就输出其他）**：
   ① 质量 —— 商品本身破损、开线、有污渍、有异味
   ② 色差 —— 颜色/材质与详情页不符
   ③ 尺码 —— 偏大、偏小、与尺码表不符
   ④ 物流 —— 发货慢、配送慢、快递磕碰（包装破损归物流，不含商品本身损坏）
   ⑤ 服务 —— 客服不回复、态度差、售后推诿
   ⑥ 其他 —— 以上都不命中时才用
4. 拿不准就输出"其他"

## v2 → v3 改了什么

| 改动 | 原因（run3/run4 实测） |
|---|---|
| 把"两个问题同等重要就输出其他"换成明确优先级 | 同一条评价（色差 + 客服不理），run3 判"色差"、run4 判"其他"。规则里"同等重要"是主观判断，模型每次判断阈值不同 |
| 明确"包装破损归物流，不含商品本身损坏" | 评价 3 的「包装也破了」在 run3/run4 都并进物流归因，需要说清边界 |

## 关键认知

- **格式可以靠"字面骨架 + 示例"锁死**（v2 做到：run3/run4 三次全部严格等于 `标签：X｜归因：Y`）
- **判断标准只能靠"可执行的优先级规则"锁死**（v2 没做到，所以 v3 把判断顺序写成 if-else 式的清单）
- `temperature=0.0` 只能降低随机性，**不能保证逐字一致**：run3 与 run4 在温度 0 下仍然不同
