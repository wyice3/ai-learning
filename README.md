## 🚀 如何运行
1. 安装 Python 3.10+ 和依赖：`python -m pip install openai python-dotenv`
2. 在项目根目录建 `.env` 文件，写入你的 API key（见 .gitignore，不会上传）
3. 运行：`python first_call.py`
